# Documentation

This folder contains the detailed technical documentation for **LeadForge AI**, organized by topic.

## 📂 Structure

| Folder | Contents |
|--------|----------|
| `product/` | Product Requirements Document (PRD) |
| `architecture/` | Tech stack, system architecture, AI architecture, project structure & conventions |
| `database/` | PostgreSQL schema specification & DDL |
| `config/` | Environment variable reference & secret management |
| `security/` | Security controls, compliance (DPDP/CAN-SPAM), threat model |
| `roadmap/` | Phased development roadmap & milestones |
| `research/` | External API & service research report |

## 🚀 Quick Start

For setup instructions, see the root [`README.md`](../README.md). For environment variable configuration, see [`docs/config/ENVIRONMENT_VARIABLES.md`](./config/ENVIRONMENT_VARIABLES.md).

## 🔒 Security

Security policies and compliance details are in [`docs/security/SECURITY_AND_COMPLIANCE.md`](./security/SECURITY_AND_COMPLIANCE.md). **Never commit secrets** — see `.gitignore`.
